Privacy Policy

Last updated: March 2026

This Privacy Policy outlines how this personal file synchronization application handles account data and Google Drive access permissions.

1. Information Access

The application requests access to Google Drive to perform file backup and synchronization tasks.

2. Data Usage and Retention

No user data, tokens, or personal information are stored, processed, or transferred through external servers associated with this website. Authentication credentials are managed locally on the authorized device.

3. Data Sharing

No personal information or account data is ever sold, rented, or shared with third parties.

4. Contact

For questions regarding this application or privacy policy, please open an issue on GitHub.
